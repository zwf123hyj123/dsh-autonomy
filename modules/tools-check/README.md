# tools-check · 工具体检

对应两条社区痛点（见 dsh-knowledge 的《DSH 痛点汇总》）：

- **5｜工具清单表**：统计每个会话里每个工具的调用数与结果数，输出工具清单表。
- **6｜探这探个修复**：探测 `tool/call` 与 `tool/result` 的 callId 配对，找出**悬空调用**（有调用无结果）与**孤儿结果**（有结果无调用），并给出修复建议（补失败结果或重试，不手改日志）。

## 用法

```sh
python3 工具体检.py              # 检查最近 8 个会话
python3 工具体检.py <sid前13位>   # 只查一个会话
```

只读 session 日志（zstd 解压后流式解析），不打印对话内容，只统计工具名与 id 配对。

## 判据

- 悬空调用 = 会话结束前应补齐；若持续存在，说明工具结果丢失或会话被截断。
- 孤儿结果 = 说明日志拼接或恢复过程出了问题，优先查 resume 路径。
