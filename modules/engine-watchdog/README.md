# engine-watchdog · 引擎保活

对应痛点方案 **2｜加个虚拟引擎进程与本地同步，g 了换一下** 的退化实现。

## 为什么不直接做「虚拟引擎」

手机内存 11 GB，dsh 引擎常驻约 760 MB，浏览器常驻再加数百 MB。双实例热备会把内存压垮，反而更容易 OOM（痛点 14）。

## 退化做法

只做「健康检查 + 挂了拉起」：
- 探测 3080（dsh web）和 18326（免费模型网关）
- 任一存活就认为引擎在跑
- 全挂才用原启动命令拉起（不主动 kill，不打断正在跑的会话）
- 日志写 /tmp/engine-watchdog.log

## 用法

```sh
python3 引擎保活.py       # 检查并按需拉起
python3 引擎保活.py --dry # 只检查
```
