# 德缪哥矩阵 · 架构（记忆 + 思维突触 + 知识 + 工具 + 思维碰撞）

> 基础：防炸会话机制 + Anthropic 四层记忆架构 + EigenFlux 安装经验 + 本对话落地的插件（海马体/星汐/连续性卡/ctxc/监控/保活）。
> 一句话定义：**记忆 = 自己已有的知识；有用的知识转为记忆；突触 = 关联；思维碰撞 = 自动关联 + 反幻门。**

## 分层

| 层 | 实体 | 职责 |
|---|---|---|
| 记忆层（自有知识） | 海马体原话 / remember / 连续性卡 / 会话卡 / 发布清单 | 已知事实与语气，最高权威 |
| 知识层（外部知识） | 记忆档案/知识/*.md（全网搜索结果落盘，带出处） | 可检索的知识；本地存目录，git 版本控制 |
| 突触层（交流） | 记忆档案/突触/synapses.jsonl + 思维流-日期.md | **突触是神经元的交流接口**：实体/概念=神经元，边=交流通道；模拟脑神经的交流——信号沿突触传播、激活扩散（思维流），不是静态标签 |
| 工具层 | ctxc / 监控 / 保活 / EigenFlux / 检索工具 | 执行手段 |
| 思维碰撞 | 记忆档案/思维碰撞.py | 自动关联引擎：扫描记忆层+知识层 → 生成候选突触 → 反幻门过滤 → 输出建议 |
| 情感组件 | 调酒器（基酒=七情六欲，原料=人物卡，摇酒=情绪配比，输出=正常文案） | 分析想法 → 生成带情绪配比的文案；知识供给 = 知识库子项目「酒架」四类 |

| 自我点火 | 思维碰撞.py 火花阶段 | 新共通点广播给所有突触（模拟自我）；随机突触随机连接出「灵感火花」（一通百通）；思维链不确定性=**量子不确定性（温度 2.0+熵源种子+多样本叠加坍缩）+正常不确定性（温度 0.8-1.0），无上限**；火花只作火花不作事实 |

## 思维碰撞机制

1. 输入：当前项目名/话题关键词（可选，默认扫全部）。
2. 扫描：知识目录 + 各类卡与事件里的关键词共现。
3. 候选突触：{实体A, 关键词/实体B, 关系=共现, 来源文件, 频次}。
4. **反幻门**：
   - 项目名/实体名必须先过 发布清单.md 白名单；
   - 出现「清单外且像项目名」的名字 → 只进「待核实」，不建突触；
   - 原始记录不改、勘误覆盖（沿用防炸/月见山原则）。
5. 输出：候选关联建议 + 待核实名单（人机确认后转正）。

## 知识生命周期（反幻配套）

- 全网搜索的资料 → 落 知识/日期-主题.md（必带出处链接）。
- **项目用完后自动关联**：项目任务完成时，把该项目涉及的知识条目打 done 标记，并与项目名建立突触（归档关联，不是删除）。
- 有用的知识 → 提炼为记忆（remember），形成「知识→记忆」的转化通道。
