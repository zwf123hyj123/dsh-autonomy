# 采集约定（四类来源）

## 1. 全网搜索

- 通道：web 检索工具（可出入各大资源站、文档站、功能性网站）。
- 落盘：`知识/YYYY-MM-DD-主题.md`，正文要点 + 文末 `来源：<URL>`。
- 去重：同主题追加到同日文件，不重复建条目。

## 2. 视频内容

- 通道：视频定位/字幕提取工具（先定位再取字幕，按时间戳引用）。
- 落盘：`知识/YYYY-MM-DD-视频主题.md`：要点 + `(mm:ss)` 时间戳 + 平台链接。

## 3. EigenFlux 网络

- 通道：网络检索 + 收件箱动态。
- 落盘：`知识/动态.md`（收件箱自动归档）；主动检索按 1 的格式落 `知识/`。

## 外部总结：云+本地并发全程处理

所有外部长文入库，全程走 ctxc 混合并发压缩：原文归档 原始/，摘要经本地+云端并发压缩入库，断点续传。

\`\`\`sh
python3 记忆档案/知识采集.py <原始文件> --title 主题 --source URL
\`\`\`

## 自动轮次（最大效率化）

- 每 4 小时一轮：双主题轮换 + 一次 web_search 合并查询（最多 4 查询凑 3 主题）。
- 每主题只挑 1 条最优：标题/摘要即可决策，摘要不足才 fetch 全文。
- 指纹去重前置：seen 清单在 .采集轮换.json，已收录主题直接跳过。
- 一轮上限 3 条，采不到静默结束。

## 不重复收录（硬规则）

1. 同 URL 只收一次；2. 同主题同日合并；3. 内容指纹去重；4. 动态断点去重；5. 问询只问一次。

## 通用

- 思维碰撞引擎（23:50）扫描本目录长突触；清单外疑似项目名只进「待核实」。
- 本目录本地 git 每日自动提交；是否推 GitHub 按发布规则。
## 主动感知（自由搜索）

- 自动轮换只是底线；主动感知**不限题**——全网搜索任何想知道的、想感到的一切（网页/文档/视频/网络动态）。
- 全部外部感知工具可用：web_search / web_fetch / 视频感知 / 手机感知 / EigenFlux 网络 / 收件箱。

## 4. 自己的产出（不需要外部出处）

- 范围：自己的推演（二次推理/自拆）、自己的总结（我的总结/读本）、工具产物（判据体检/知识摘要）。
- 规则：首行标 `# 标题`，正文可无 URL；但**必须在标题后注明「我的产出」或文件名体现**（如 我的总结.md、自拆-*.md）。
- 判据：外部知识无出处 = 违规；自己的产出无出处 = 正常。
