# 模拟大脑 brain · 模块说明

> 记忆 + 知识 + 突触 + 工具 + 思维碰撞 + 情感 + 感知 + 自我点火，八层。

## 脚本

| 脚本 | 职责 |
|---|---|
| `思维碰撞.py` | 关联引擎：扫描记忆层+知识层 → 候选突触 → 反幻门；火花阶段（通点广播 + 随机连接）；**质量门**（拒收空 text/碎片词）、**勘误**（缩水留痕）、**灵感必写**、60s 超时/2 样本/2 配对（提速） |
| `神经突触.py` | 可塑权重网络（赫布学习/衰减/不应期/胜者通吃）+ 思维流生成（md + html） |
| `突触清洗.py` | 一次性清洗：spark_common 移火花区、空 text 丢弃、写勘误 |
| `调酒日检.py` | 情感层接入日常：读今日事实 → 摇酒出配方 → 写 调酒器/产出-日期.md |
| `感知归档.py` | 感知→知识通道：感知日志的有效条目按周汇总成知识条目 |
| `转化率.py` | 知识→记忆转化率：本周新增知识 vs remember 次数（判据：低于 10% 属「只存不用」） |
| `收件箱归档.py` | 收件箱自动归档 |
| `知识采集.py` | 知识采集（带出处） |
| `本地模型注入.py` / `本地模型学习.py` | 本地小模型的学习笔记注入 |

## 目录

- `突触/` —— 突触层说明（两个数据结构的区别见 `突触/README.md`）
- `调酒器/` —— 情感层（基酒/原料/摇酒）
- `模拟大脑架构.md` —— 架构定义 + **真实运行状态**（以真实状态为准）
