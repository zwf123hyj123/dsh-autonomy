# 八层自检清单（2026-11-25）

> 用途：查漏补缺时按此清单逐层检查。每层都有「命令 / 判据 / 修法」——
> **说不清判据的不算查过。** 命令都在 `/root/workspace/记忆档案/` 下执行。

## 1. 记忆层

- **查**：`ls 连续性/会话卡/*.md | wc -l`；`python3 会话卡体检.py`
- **判据**：死链要么 0，要么首行已标「原会话已不存在 + 抢救件」
- **修**：`python3 会话卡体检.py --apply`

## 2. 知识层

- **查**：`python3 消化.py --status`；`python3 知识出处体检.py`
- **判据**：待消化 0；外部知识无出处违规 0
- **修**：`python3 批量消化.py --apply`；`python3 补摘要.py`；`python3 转化率.py` 看转化

## 3. 突触层

- **查**：`wc -l 突触/synapses.jsonl`；随机抽 3 条看 from→to
- **判据**：≥10 条；from/to 是**实体**（不是 URL/hash/路径片段）；text 带来源
- **修**：把垃圾移火花区（`突触/synapses.jsonl.bak-*` 留档）

## 4. 工具层

- **查**：`python3 /root/workspace/dsh-ctxc/scripts/巡检.py`；`for f in *.py; do python3 -c "import ast;ast.parse(open('$f').read())"; done`

- **修**：按报错修；keepalive 缺失由巡检自愈

## 5. 思维碰撞

- **判据**：候选 ≥30；突触数稳定或增长；无新增垃圾
- **修**：调 `build_entities`（实体词典）/ `is_quality`（质量门）/ STOP 表

## 6. 情感层
