# engine · 引擎层

内用版这一层的五个脚本，同步过来时只做了两件事：**路径走环境变量**、**去掉维护者相关表述**。逻辑一行没改。

| 脚本 | 干什么 | 依赖 |
|---|---|---|
| `思维碰撞.py` | 从知识里抽候选，找结构相通的两两配对（含 `--intense/--trance/--crazy` 三档） | 模型接口（可选）、`data/知识` |
| `神经突触.py` | 实体共现 → 权重网，按轮次发放激活 | `data/突触/` |
| `突触清洗.py` | 把日志来源、hash 碎片、脑补叙事清出图，挪进火花区 | 上面两个 |
| `建索引.py` | 中文二元组关键词索引，不依赖模型 | `SIMBRAIN_KNOW` |
| `查.py` | 用索引检索 | 同上 |

**冒烟记录（2026-11-27）**：隔离目录里 `建索引.py` 建出 1 篇 27 词元、`查.py "断开压缩"` 命中；`神经突触.py` 在空数据上输出「节点 0 / 边 0」不报错；`思维碰撞.py --no-spark` 正常返回候选。

**这一层不发布数据**：`nodes.jsonl`、`synapses.json`、`火花-*.jsonl` 都是运行产物，只在本地。
