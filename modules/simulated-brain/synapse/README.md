# 突触层 · 目录说明（2026-11-25 定）

这里有两个**不同用途**的数据结构，名字像但不是一回事，别再混：

| 文件 | 谁写 | 是什么 | 用途 |
|---|---|---|---|
| `synapses.json` | 神经突触.py | **权重网络**：edges/nodes/last，带赫布学习权重、衰减、不应期 | 模拟神经发放与可塑性 |
| `synapses.jsonl` | 思维碰撞.py | **关联记录**：一行一条 from→to，含 rel/text | 可检索的关联明细 |
| `火花-<日期>.jsonl` | 思维碰撞.py | **火花区**：spark_common（通点广播）落这里，不进主突触 | 灵感来源，不算「真突触」 |
| `灵感-<日期>.md` | 思维碰撞.py | 火花文案（本地模型自由联想） | 人读 |
| `思维流-<日期>.md/.html` | 神经突触.py | 当日发放序列与可视化 | 看「怎么想的」 |
| `勘误-<日期>.md` | 思维碰撞.py / 突触清洗.py | 删除/缩水记录 | 反幻门：原始记录不改，但要留痕 |

## 质量判据（2026-11-25 立）

- text < 2 字符 → 拒收
- from/to < 2 字符或属碎片词（每轮对话/后自动滚/原文已归…）→ 拒收
- spark_common 一律进火花区，不混进 synapses.jsonl
