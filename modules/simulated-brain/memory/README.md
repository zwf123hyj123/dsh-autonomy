# memory · 记忆层（情感并入）

内用版把「情感」当作情绪记忆并入记忆层，所以这里放的是调酒器的**方法**而不是记忆内容：

| 文件 | 是什么 |
|---|---|
| `基酒.json` | 七情六欲 → 基酒配方（风味、类别、适用场合）。纯配方，不含任何人的状态 |
| `摇酒.py` | 情绪识别 → 配比 → 口吻；模型不可用时退回规则版（毫秒级、不编内容） |

**不同步的**：`原料/`（人物设定卡，属于具体的人）、`产出-*.md`（每天的情绪记录）。判据还是那条——只发方法，不发人与关系。

用法：把 `基酒.json` 当起点，按自己的场景改配方；`摇酒.py` 里 `classify/pick_bases` 两个函数是最小可复用单元。
