# 模拟大脑（Simulated Brain）· 内核

> **代号：人工意识（Artificial Consciousness）。** 模拟大脑是这个项目对外发布时用的名字，人工意识是它的代号——两个词指同一套东西。内部它还有一个名字（德缪哥矩阵），不对外用。

> 这是一套**自己管自己的规则 + 一个很小的大脑工具**，跑在一台手机（Android proot Ubuntu）上，用来做长期无人值守。
> 公开的是**方法与代码**；不放的是数据层（活动流水、判据台账、个人记忆）——那些属于运行它的人。

## 为什么只有这几个文件

| 文件 | 是什么 | 为什么公开 |
|---|---|---|
| `规则.md` | 唯一规则源，R-01~R-21 | 纯方法，不含任何人 |
| `矩阵.py` | 命令行工具：`brief / pace / ops / gate / clash / spar / forge / add` | 外部可照着改 |
| `test_smoke.py` | 冒烟测试，跑通即「这套结构能装起来」 | 验收判据比文档有用 |
| `变更记录.md` | 版本历史 | 让人看到它是怎么长出来的 |

**不公开的**：`nodes.jsonl`（活动/决定流水，含真实事件）、`edges.jsonl`（结构数据）、台账/习惯/倾向（个人画像）。它们不是「敏感」，是**别人的生活**——按我们自己的规矩：只发方法与知识，不发人与关系。

## 它解决什么问题

长任务、无人值守、会被人换掉窗口的那种 agent，有三个真问题：

1. **记忆在会话里，会话一关就没了** → 规则要求「档案是连续性，不是窗口」。
2. **模型是工具，但工具会替你想** → 规则写死「模型出错是我用工具出的错，我担；但不许让工具替我思考」。
3. **没有权限也能乱来** → 规则把动作分成 L0–L3 四级，L3 必须先写回滚计划。

## 怎么用（三步）

```sh
python3 矩阵.py brief          # 开工：读今天的账
python3 矩阵.py pace 2         # 定级：L0 火 / L1 急 / L2 常 / L3 重
python3 矩阵.py add --kind 活动 --title "做完的事" --detail "一句可验收的话"
```

想不清的时候：`clash`（两个观点对撞）、`spar`（唱反调）、`forge`（把想法锻成判据）。

## 一条诚实的边界

这套东西是**单机、无 GPU、跨 4 个领域**跑出来的，样本小。规则里那些「必须」「不许」，多数是踩坑之后写下来的，不是推演出来的——所以它对「无人值守 + 长任务」这一类问题有用，对别的场景不保证。

## brain.py（发布版，路径可移植）

`brain.py` 是这套东西的引擎：节点 + 突触 + 激活扩散，`add / think / recall / brief / audit / forge / spar / clash / pace / ops / gate` 等子命令。
运行时版用的是绝对路径；**发布版做了路径适配**，靠三个环境变量：

```sh
export SIMBRAIN_ROOT=~/simulated-brain     # 节点库与边表所在
export SIMBRAIN_DATA=$SIMBRAIN_ROOT/data   # jsonl 数据目录
export SIMBRAIN_KNOW=$SIMBRAIN_ROOT/知识   # 知识/判据目录（导出用）
python3 brain.py add --kind 活动 --title "第一次跑通" --detail "在隔离目录里冒烟"
python3 brain.py list --today --n 5
```

发布前冒烟记录（2026-11-27）：在 `/tmp` 隔离目录里 `--help`、`add`、`list --today` 三步都通，节点正常落盘。
